
# React Weather App

Welcome to the Weather App. This project is a web application that provides real-time weather updates for any location. It utilizes HTML, CSS, JavaScript and React to deliver a user-friendly interface and fetches data using the OpenWeatherMap API.


## Features

- Search for weather data by country, state or city name.
- Displays current temperature, weather conditions, and an icon representing the weather.
- 5-day weather forecast.
- Get up-to-date weather information for your current location


## Technologies Used

- React: A JavaScript library for building user interfaces.
- OpenWeatherMap API: Fetches real-time weather data and forecasts.

## Installation

Install weather app commands

```bash
  1. npm install
  2. npm i axios
  3. npm i country-state-city
```
    
## Usage

To use the Weather App, simply enter the name of the city in the select field and press search. The app will display the current weather conditions, including temperature, humidity and wind speed.
